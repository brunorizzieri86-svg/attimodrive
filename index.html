Respostas diretas para você começar com segurança.

Posso conhecer antes de colocar meus dados?

Sim. O site apresenta prévias das telas com dados fictícios. Para explorar as funções, abra o aplicativo e procure o modo demonstração disponível nele.

Preciso instalar algum programa?

Você pode começar pelo navegador. O aplicativo também oferece a opção de instalação como app no Chrome ou Edge, com ícone no computador. Abra o app e use o botão “Instalar aplicativo”.

O aplicativo funciona sem internet?

Após o primeiro carregamento e a preparação para uso offline, as funções locais podem funcionar sem conexão. O acesso inicial, o WhatsApp e serviços externos precisam de internet.

Onde ficam as informações da minha oficina?

No armazenamento local do navegador usado para acessar o aplicativo. Faça e guarde seus backups. Limpar os dados do navegador, trocar de dispositivo ou acessar por outro endereço não transfere os dados automaticamente.

Meu funcionário pode acessar sem ver o financeiro?

Sim. O aplicativo permite configurar uma senha de funcionário e escolher as permissões de acesso no mesmo ambiente local. Isso não cria sincronização automática entre computadores.

Como envio um orçamento para o cliente?

Prepare o orçamento com serviços e peças no aplicativo. Você pode gerar o documento para impressão ou salvar como PDF pela impressão do navegador, e preparar a mensagem para abrir no WhatsApp.
